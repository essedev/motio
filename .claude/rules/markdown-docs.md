- English prose (public repository), no em dashes, no section sign, no emoji.
- Docs change in the same commit as the code they describe.
- No number the repository can compute (counts of files, tests, symbols): point to the command instead.
- `docs/DECISIONS.md` entries are append-only: a changed decision gets a new entry that supersedes the old one.
