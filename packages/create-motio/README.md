# create-motio

Creates a new [Motio](../../README.md) project: React components rendered to video.

```bash
pnpm create motio my-video
npm create motio@latest my-video
yarn create motio my-video
bun create motio my-video
```

It runs `motio init` with the same arguments, so every flag of `motio init` works here: `--template basic|blank|captions`, `--pm pnpm|npm|yarn|bun`, `--no-install`, `--yes`, `--force`, `--name`, `--json`. On a terminal it asks for what the flags leave out. The [getting started guide](../../docs/guide/getting-started.md) walks through the generated project.
